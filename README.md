# Header Menu

[![Build Status](https://github.com/vinny/phpbb-menu/actions/workflows/tests.yml/badge.svg)](https://github.com/vinny/phpbb-menu/actions)

Header Menu is a phpBB 3.3+ extension that allows administrators to create, reorder, and manage a custom navigation menu in the forum header.

## Features

- **Custom navigation links**: Add, edit, reorder, and delete links in the forum header menu.
- **Nested submenus**: Create multi-tier dropdown menus up to 3 levels deep.
- **Item descriptions**: Add optional short descriptions under level 2 and level 3 dropdown items.
- **Custom colours**: Customise menu background, text, hover states, and dropdown colours directly from the ACP.
- **Drag-and-drop reordering**: Reorder items and adjust parent-child hierarchy in the ACP with instant updates.
- **Link targets**: Open links in the current tab (`_self`) or a new tab (`_blank`).
- **Group-based visibility**: Hide specific menu items from selected user groups.
- **Item status toggle**: Enable or disable individual menu items, or turn off the entire menu globally.
- **Integrated search box**: Optionally show a search box inside the menu bar.
- **Responsive menu**: Mobile-friendly toggle menu bar for smaller screens.

## Requirements

- phpBB 3.3.0 or higher
- PHP 7.2.0 or higher

## Installation

1. Download the latest release.
2. Unzip the contents into the `ext/vinny/menu` directory of your phpBB installation.
3. In the ACP, navigate to **Customise > Manage extensions**.
4. Click **Enable** under **Header Menu**.
